## 已确认的决策(2026-07-31,WORKORDER 已同步)

**D1 —「短文本」与「书」合并 ✅**
书架里每一项都是书、都带进度指针。`Save custom text` 的 `Long text (book mode)` 勾选框取消(保存即建书);旧的无进度 `customText` 首次进书架时迁移为 `progress: 0` 的书。
- 理由:产品本体就是"打自己的书",两套语义无意义;M3 指针制要求每本都有指针。
- 已知代价:短片段加载后也会出现"编辑文本会关闭进度追踪"的遮罩(语义正确,对短片段略啰嗦)。

**D3 — limit 输入区**保留**(改判,原裁剪表写的是删)✅**
`words` / `time` 两个输入框留着,repeat / shuffle / random 仍可手动指定"打 N 词 / N 秒"。`sections` 那一格随 pipe delimiter 一起消失(它只在 pipe 模式下显示)。打书的每轮字数/时间不走这里,由 M3 书籍打字页的「回合设置」实现。
- WORKORDER「Custom 弹窗裁剪表」已改写该行并注明改判日期与理由。

**D2 / D4** 按 WORKORDER 裁剪表原文执行:`saved texts` 按钮 → 书架入口;`words filter` 删。

**D5 — 上传入口 = 书架末尾的虚线卡 ✅(用户定 2026-07-31)**
不做顶部工具栏按钮。虚线边框 + 上传按钮,排在所有书卡之后、占一个书卡的格子;书架为空时它就是页面主体(取代 M2b 那个纯文字空态)。

**D6 — M2c 一次吃下全部格式 ✅(用户拍板 2026-07-31)**
`txt / md / docx / pdf / epub` + 粘贴,一片做完,不分批。验收标准是用户原话「**提取字符就好**」:拿到正文文字流即可,页眉页脚 / 章节 / 分页对齐 / 扫描版 OCR 仍归 M4。

**D7 — 胶囊条与左右箭头提前到 M2d ✅(用户拍板 2026-07-31)**
原在 M3。基于 M2b 已有的词级指针做简版,让"打自己的书"的手感尽早能上手。**默认 25 词**(用户否掉了推荐的 50),字数档 `25/50/100/200`,时间档 `15/30/60/120` 秒。

### M2d — 打书回合胶囊条 + 左右箭头(词级简版,D7)

- **胶囊条**:打书时在打字区上方显示,复用 random 页那套 `TestConfig` 胶囊样式:`words | time` 两组 + 档位(`25/50/100/200` 词、`15/30/60/120` 秒),**默认 25 词**。选择存进书里(每本书记住自己的回合设置)。
