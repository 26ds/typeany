   - `SaveCustomTextModal` 的 `Long text (book mode)` 勾选 → 存进 localStorage `customTextLong`:`{ [name]: { text: string, progress: number } }`(`test/custom-text.ts:12-16`)。

7. 现 `/bookshelf` 是 M1d 的占位卡片(`BookshelfPage.tsx`,49 行),M2b 整体重写。

## 已确认的决策(2026-07-31,WORKORDER 已同步)

**D1 —「短文本」与「书」合并 ✅**
书架里每一项都是书、都带进度指针。`Save custom text` 的 `Long text (book mode)` 勾选框取消(保存即建书);旧的无进度 `customText` 首次进书架时迁移为 `progress: 0` 的书。
- 理由:产品本体就是"打自己的书",两套语义无意义;M3 指针制要求每本都有指针。
- 已知代价:短片段加载后也会出现"编辑文本会关闭进度追踪"的遮罩(语义正确,对短片段略啰嗦)。

**D3 — limit 输入区**保留**(改判,原裁剪表写的是删)✅**
`words` / `time` 两个输入框留着,repeat / shuffle / random 仍可手动指定"打 N 词 / N 秒"。`sections` 那一格随 pipe delimiter 一起消失(它只在 pipe 模式下显示)。打书的每轮字数/时间不走这里,由 M3 书籍打字页的「回合设置」实现。
- WORKORDER「Custom 弹窗裁剪表」已改写该行并注明改判日期与理由。

**D2 / D4** 按 WORKORDER 裁剪表原文执行:`saved texts` 按钮 → 书架入口;`words filter` 删。
